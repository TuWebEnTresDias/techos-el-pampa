# techos-el-pampa

Sitio web personalizado para Techos El Pampa. Sitio estático preparado a partir de la demo de Techistas Digitalizados y adaptado con los datos disponibles del lead.

## Contenido

- Atención en Tandil, Rauch, Las Flores y Azul.
- Consultas dirigidas al WhatsApp `+54 9 2494 33-1124`.
- Galería con las cuatro fotos que compartió el lead.
- Diseño responsive sin formularios ni dependencias externas.

El chat no incluía un listado explícito de servicios. Por eso, la página usa una presentación general de trabajos en techos y evita atribuir técnicas, garantías, experiencia o servicios que no fueron confirmados. Conviene confirmar el listado de servicios con el lead antes de dar por finalizada la versión.

La vista está marcada `noindex, nofollow` mientras se use como preview. Al pasar a un dominio público definitivo, revisar y actualizar esa directiva.
